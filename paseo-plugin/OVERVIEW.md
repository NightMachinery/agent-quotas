# Agent quotas

Open **Agent quotas** from the active agent's Command Center. The panel shows
the selected agent's quota verdict, auto-continue registration, cache policy
phase and next scheduled action. Use it to set auto-continue or cache policy,
put the agent on standby, or request a compaction.

The panel talks to agent-quotas on the same machine as the selected Paseo
daemon. The agent-quotas keeper must be enabled for cache controls.
